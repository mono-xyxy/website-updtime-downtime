# 🌐 Website Uptime Checker (Python CLI)

A simple Python command-line tool that checks whether a website is **online or offline** by sending an HTTP request.

---

# 📌 Features

* Check if a website is **UP or DOWN**
* Displays HTTP status code
* Handles network errors
* Simple CLI interface

---

# 📂 Project Structure

```
website_uptime_checker
│
├── uptime_checker.py
├── requirements.txt
└── README.md
```

---

# ⚙ Requirements

* Python **3.x**
* `requests` library

Install dependency:

```bash
pip install requests
```

---

# 🚀 Run the Program

Navigate to the project folder:

```bash
cd website_uptime_checker
```

Run the script:

```bash
python uptime_checker.py
```

---

# 💻 Example

```
Enter website URL: https://google.com

https://google.com is UP ✅
```

# 🧠 Concepts Used

* HTTP requests with `requests`
